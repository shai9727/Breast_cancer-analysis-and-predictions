# Breast_cancer-analysis-and-predictions

The project analyzes tumor characteristics, performs exploratory data analysis, develops multiple machine learning classification models, evaluates their performance, identifies important predictive features.


##objectives
Clean and prepare breast cancer data for analysis
Explore tumor characteristics using statistical and visual analysis
Analyze relationships between tumor features
Compare different machine learning algorithms
Evaluate models using multiple performance metrics
Identify important features contributing to model predictions
Develop a reproducible healthcare machine learning project for a data analytics portfolio
